# About dac.zip file

Android Knowledge Base (AKB) is live [in google3](
http://google3/devrel/android/knowledge_base/;rcl=804771441). You can get `dac.zip` file by running
```shell
g4d -f <CLIENT NAME>  # replace <CLIENT NAME> with your client name
blaze build //devrel/android/knowledge_base:latest_kb_archive
```
You can check the artifact in
`blaze-bin/devrel/android/knowledge_base/kb.zip`.

This prebuilt is generated by a purpose-built tool in google3 that precomputes
a Lucene index over the KB contents, and includes it in the ZIP file in a way
that allows `ZipDirectory` in `//tools/vendor/google/ml/aiplugin/rag/kb` to
serve queries directly out of the ZIP, without needing to decompress anything,
even in memory. This involves aligning the contents of the ZIP file to page
boundaries so that Lucene can `mmap` the contents directly. **Please do not
modify or recompress the ZIP file**, since this will break that alignment. If
you need to make changes to the prebuilt, make changes to the tool in google3,
rerun it, and check in the resulting ZIP file. The ZIP generator tool can be
found in google3 at
http://google3/java/com/google/wireless/android/devtools/studio/ml/rag/akb/AkbIndexGenerator.kt.

In google3, the prebuilt-index tool is run daily by a Pod job, and the results
are copied to x20 and sent to Lorry. See the script that manages this upload at
http://google3/devrel/android/adrailab/dac_extract/upload_to_lorry.py. This
allows us to download the most up-to-date version of the Android knowledge base,
including a new index. However, it is important to have a copy included with the
GCA plugin, so that in the event of download issues, lack of disk space, etc.,
the RAG plugin will continue to operate.
